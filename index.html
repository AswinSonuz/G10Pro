Step 1. Go to console.firebase.google.com
Step 2. Click "Add project" → name it g10pro → create
Step 3. Click "Realtime Database" → Create database → Start in test mode
Step 4. Go to Project Settings ⚙️ → Your apps → Add web app
Step 5. Copy the databaseURL (ends with .firebaseio.com)
Step 6. Copy the full firebaseConfig object and paste below
